# السكرتير الذكي على واتساب

[English](README.md)

سكرتير شخصي يعمل من خلال واتساب. يمكنك مراسلته كتابياً أو صوتياً باللغة العربية أو الإنجليزية، ليقوم بجدولة مهامك، وتذكيرك بها قبل مواعيدها، وإرسال ملخص صباحي ومسائي عن يومك، إضافةً إلى مراجعة في نهاية كل أسبوع.

> **الحالة:** يعمل حالياً ضمن نسخة تجريبية خاصة مع ٤ مستخدمين، ويجري تطويره باستمرار بناءً على ملاحظاتهم.

## الخدمات التي يقدمها

- **إدارة المهام:** يكفي أن تكتب مثلاً "ذكرني بكرة الساعة خمس إلا ربع عندي اختبار كيمياء" أو "أجّل النادي لبكرة"، ليتولى إضافة المهمة أو تعديل موعدها أو إنجازها أو حذفها، دون الحاجة إلى قوائم أو أوامر محددة.
- **الرسائل الصوتية:** يمكنك إرسال رسالة صوتية بدلاً من الكتابة، لتنفيذ الإجراءات نفسها: إضافة مهمة، أو تأجيلها، أو تسجيلها كمنجزة.
- **الملخصات اليومية والأسبوعية:** ملخص صباحي بمهام اليوم، وتذكير قبل كل مهمة، وملخص مسائي بما أُنجز وما فات، ومراجعة في نهاية الأسبوع.
- **المهام المتكررة:** عبارة مثل "كل جمعة بعد العشاء" تتحول إلى مهمة متكررة فعلية، مع الاحتفاظ بصياغتك الأصلية في الردود.
- **الردود السريعة:** تصل التذكيرات مع أزرار "تم" و"إعادة الجدولة" و"أقرر لاحقاً"، كما يمكن الرد كتابياً بالطريقة نفسها.

## أمثلة

| رسالة المستخدم | الإجراء |
|---|---|
| ذكرني أتصل على أمي بعد نص ساعة | إضافة تذكير بعد ٣٠ دقيقة |
| عندي موعد أسنان بعد ثلاث أيام الساعة ٤ | إضافة الموعد والتذكير به مسبقاً |
| ذكرني كل يوم أروح النادي الساعة ثمانية بعد العشاء | إضافة مهمة يومية متكررة |
| انقل الاجتماع للساعة سبع | تعديل موعد الاجتماع |
| وش عندي اليوم؟ | عرض مهام اليوم |
